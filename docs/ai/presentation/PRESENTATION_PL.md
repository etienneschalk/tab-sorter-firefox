Rozszerzenie Tab Sorter

Efektywnie organizuj karty przeglądarki

Tab Sorter to rozszerzenie przeglądarki, które pomaga organizować otwarte karty za pomocą różnych metod sortowania. Utrzymuj porządek w przeglądaniu i szybko znajduj karty.

Funkcje

Opcje sortowania
- Według tytułu - Organizacja alfabetyczna
- Według URL/domeny - Grupowanie podobnych stron
- Według favicon - Wizualne grupowanie według ikon witryn
- Ostatnio używane - Sortowanie według ostatniej aktywności
- Losowo - Losowa kolejność kart

Obsługa grup kart
- Uwzględnia grupy kart przeglądarki podczas sortowania (Chrome 89+, Firefox 137+)
- Karty w każdej grupie są sortowane osobno
- Grupy zachowują swoje pierwotne pozycje
- Opcja wyłączenia dla klasycznego zachowania

Skróty klawiszowe
- Ctrl+Shift+Spacja - Sortuj karty preferowaną metodą
- Ctrl+Shift+L - Wyodrębnij domenę (przenieś karty tej samej domeny do nowego okna)

Obsługa zawieszonych kart
- Elastyczne opcje obsługi zawieszonych (odrzuconych) kart podczas sortowania
- Trzy wybory pozycji: Ignoruj, Grupuj na końcu lub Grupuj na początku
- Pomaga utrzymać aktywne karty łatwo dostępne lub najpierw przejrzeć zawieszone
- Działa ze wszystkimi metodami sortowania

Obsługa przypiętych kart
- Opcja niezależnego sortowania przypiętych kart
- Przypięte karty są sortowane między sobą, pozostając przypięte
- Działa ze wszystkimi metodami sortowania

Obsługa trybu ciemnego
- Motyw automatyczny (zgodny z systemem) jest domyślny
- Automatyczne wykrywanie motywu systemowego
- Ręczny wybór motywu (Auto, Ciemny, Jasny)
- Natychmiastowa zmiana motywu

Dodatkowe funkcje
- Automatyczne sortowanie - Automatyczna organizacja nowych kart
- Obsługa wielu okien - Działa we wszystkich oknach przeglądarki
- Wielojęzyczny interfejs - Obsługa 25 języków
- Skupienie na prywatności - Brak zbierania danych, tylko lokalne przetwarzanie

Jak używać

1. Zainstaluj rozszerzenie ze sklepu przeglądarki
2. Kliknij ikonę Tab Sorter lub użyj skrótów klawiszowych
3. Wybierz preferowaną metodę sortowania
4. Twoje karty zostaną natychmiast uporządkowane

Zgodność z przeglądarkami

- Firefox - Dostępne w Mozilla Add-ons
- Chrome/Chromium - Dostępne w Chrome Web Store
- Działa ze wszystkimi przeglądarkami opartymi na Chromium

Instalacja

Firefox
Odwiedź sklep Firefox Add-ons, aby zainstalować.

Chrome
Odwiedź Chrome Web Store, aby zainstalować.

Prywatność

- Brak zbierania danych
- Tylko lokalne przetwarzanie
- Minimalne wymagane uprawnienia
- Kod open source
