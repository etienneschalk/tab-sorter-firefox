Tab Sorter 擴充功能

高效整理您的瀏覽器分頁

Tab Sorter 是一款瀏覽器擴充功能，可協助您使用多種排序方式整理開啟的分頁。讓瀏覽井然有序，快速找到分頁。

功能

排序選項
- 依標題 - 依字母順序整理
- 依 URL/網域 - 將相似網站分組
- 依網站圖示 - 依網站圖示進行視覺分組
- 最近使用 - 依最近活動排序
- 隨機排列 - 隨機化分頁順序

分頁群組支援
- 排序時尊重瀏覽器分頁群組（Chrome 89+、Firefox 137+）
- 每個群組內的分頁單獨排序
- 群組保持原有位置
- 可停用以恢復經典行為

鍵盤快速鍵
- Ctrl+Shift+空格 - 使用您偏好的方式排序分頁
- Ctrl+Shift+L - 擷取網域（將相同網域的分頁移至新視窗）

休眠分頁支援
- 排序時靈活處理休眠（已捨棄）分頁的選項
- 三種位置選擇：忽略、在末尾分組或在開頭分組
- 有助於保持活動分頁易於存取，或優先檢視休眠分頁
- 適用於所有排序方式

固定分頁支援
- 可獨立排序固定分頁的選項
- 固定分頁在保持固定的同時相互排序
- 適用於所有排序方式

深色模式支援
- 自動主題（跟隨系統）為預設
- 自動偵測系統主題
- 手動主題選擇（自動、深色、淺色）
- 即時切換主題

其他功能
- 自動排序 - 自動整理新分頁
- 跨視窗支援 - 適用於所有瀏覽器視窗
- 多語言介面 - 支援 25 種語言
- 注重隱私 - 不收集資料，僅本地處理

使用方法

1. 從瀏覽器商店安裝擴充功能
2. 點擊 Tab Sorter 圖示或使用鍵盤快速鍵
3. 選擇您偏好的排序方式
4. 分頁將立即整理完成

瀏覽器相容性

- Firefox - 可在 Mozilla 附加元件中取得
- Chrome/Chromium - 可在 Chrome 線上應用程式商店中取得
- 適用於所有基於 Chromium 的瀏覽器

安裝

Firefox
造訪 Firefox 附加元件商店進行安裝。

Chrome
