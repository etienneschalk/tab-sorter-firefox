Extensão Tab Sorter

Organize as suas separadores do navegador de forma eficiente

Tab Sorter é uma extensão de navegador que o ajuda a organizar os separadores abertos utilizando vários métodos de ordenação. Mantenha a sua navegação organizada e encontre separadores rapidamente.

Funcionalidades

Opções de ordenação
- Por título - Organização alfabética
- Por URL/domínio - Agrupar sites semelhantes
- Por favicon - Agrupamento visual por ícones dos sites
- Mais recentemente utilizados - Ordenar por atividade recente
- Baralhar - Aleatorizar a ordem dos separadores

Suporte a grupos de separadores
- Respeita os grupos de separadores do navegador durante a ordenação (Chrome 89+, Firefox 137+)
- Os separadores dentro de cada grupo são ordenados separadamente
- Os grupos mantêm as suas posições originais
- Opção para desativar e voltar ao comportamento clássico

Atalhos de teclado
- Ctrl+Shift+Espaço - Ordenar separadores com o seu método preferido
- Ctrl+Shift+L - Extrair domínio (mover separadores do mesmo domínio para uma nova janela)

Suporte a separadores suspensos
- Opções flexíveis para lidar com separadores suspensos (descartados) ao ordenar
- Três opções de posição: Ignorar, Agrupar no final ou Agrupar no início
- Ajuda a manter os separadores ativos facilmente acessíveis ou rever os suspensos primeiro
- Funciona com todos os métodos de ordenação

Suporte a separadores fixados
- Opção para ordenar separadores fixados de forma independente
- Os separadores fixados são ordenados entre si permanecendo fixados
- Funciona com todos os métodos de ordenação

Suporte ao modo escuro
- O tema automático (segue o sistema) é o predefinido
- Deteção automática do tema do sistema
- Seleção manual do tema (Auto, Escuro, Claro)
- Mudança de tema instantânea

Funcionalidades adicionais
- Ordenação automática - Organizar automaticamente novos separadores
- Suporte entre janelas - Funciona em todas as janelas do navegador
- Interface multilingue - Suporte para 25 idiomas
- Focada na privacidade - Sem recolha de dados, apenas processamento local

Como utilizar

1. Instale a extensão na loja do seu navegador
2. Clique no ícone do Tab Sorter ou utilize os atalhos de teclado
3. Selecione o seu método de ordenação preferido
4. Os seus separadores serão organizados instantaneamente

Compatibilidade do navegador

- Firefox - Disponível na Mozilla Add-ons
- Chrome/Chromium - Disponível na Chrome Web Store
- Funciona com todos os navegadores baseados em Chromium
