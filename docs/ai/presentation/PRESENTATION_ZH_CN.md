Tab Sorter 扩展

高效整理您的浏览器标签页

Tab Sorter 是一款浏览器扩展，可帮助您使用多种排序方法整理打开的标签页。保持浏览井然有序，快速找到标签页。

功能

排序选项
- 按标题 - 按字母顺序整理
- 按 URL/域名 - 将相似网站分组
- 按网站图标 - 按站点图标进行视觉分组
- 最近使用 - 按最近活动排序
- 随机排列 - 随机化标签页顺序

标签页分组支持
- 排序时尊重浏览器标签页分组（Chrome 89+、Firefox 137+）
- 每个分组内的标签页单独排序
- 分组保持原有位置
- 可禁用以恢复经典行为

键盘快捷键
- Ctrl+Shift+空格 - 使用您偏好的方法排序标签页
- Ctrl+Shift+L - 提取域名（将同域名标签页移至新窗口）

休眠标签页支持
- 排序时灵活处理休眠（已丢弃）标签页的选项
- 三种位置选择：忽略、在末尾分组或在开头分组
- 帮助保持活动标签页易于访问，或优先查看休眠标签页
- 适用于所有排序方法

固定标签页支持
- 可独立排序固定标签页的选项
- 固定标签页在保持固定的同时相互排序
- 适用于所有排序方法

深色模式支持
- 自动主题（跟随系统）为默认设置
- 自动检测系统主题
- 手动主题选择（自动、深色、浅色）
- 即时切换主题

其他功能
- 自动排序 - 自动整理新标签页
- 跨窗口支持 - 适用于所有浏览器窗口
- 多语言界面 - 支持 25 种语言
- 注重隐私 - 不收集数据，仅本地处理

使用方法

1. 从浏览器商店安装扩展
2. 点击 Tab Sorter 图标或使用键盘快捷键
3. 选择您偏好的排序方法
4. 标签页将立即整理完成

浏览器兼容性

- Firefox - 可在 Mozilla 附加组件中获取
- Chrome/Chromium - 可在 Chrome 网上应用店中获取
- 适用于所有基于 Chromium 的浏览器
