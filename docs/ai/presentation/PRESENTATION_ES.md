Extensión Tab Sorter

Organiza tus pestañas del navegador de forma eficiente

Tab Sorter es una extensión de navegador que te ayuda a organizar tus pestañas abiertas mediante varios métodos de ordenación. Mantén tu navegación organizada y encuentra pestañas rápidamente.

Funciones

Opciones de ordenación
- Por título - Organización alfabética
- Por URL/dominio - Agrupar sitios web similares
- Por favicon - Agrupación visual por iconos de sitios
- Más recientemente usadas - Ordenar por actividad reciente
- Mezclar - Aleatorizar el orden de las pestañas

Compatibilidad con grupos de pestañas
- Respeta los grupos de pestañas del navegador al ordenar (Chrome 89+, Firefox 137+)
- Las pestañas dentro de cada grupo se ordenan por separado
- Los grupos mantienen sus posiciones originales
- Opción para desactivar y volver al comportamiento clásico

Atajos de teclado
- Ctrl+Mayús+Espacio - Ordenar pestañas con tu método preferido
- Ctrl+Mayús+L - Extraer dominio (mover pestañas del mismo dominio a una ventana nueva)

Compatibilidad con pestañas suspendidas
- Opciones flexibles para gestionar pestañas suspendidas (descartadas) al ordenar
- Tres opciones de posición: Ignorar, Agrupar al final o Agrupar al principio
- Ayuda a mantener las pestañas activas accesibles o revisar primero las suspendidas
- Funciona con todos los métodos de ordenación

Compatibilidad con pestañas fijadas
- Opción para ordenar pestañas fijadas de forma independiente
- Las pestañas fijadas se ordenan entre sí permaneciendo fijadas
- Funciona con todos los métodos de ordenación

Compatibilidad con modo oscuro
- El tema automático (sigue el sistema) es el predeterminado
- Detección automática del tema del sistema
- Selección manual del tema (Auto, Oscuro, Claro)
- Cambio de tema instantáneo

Funciones adicionales
- Ordenación automática - Organizar automáticamente las pestañas nuevas
- Compatibilidad entre ventanas - Funciona en todas las ventanas del navegador
- Interfaz multilingüe - Compatibilidad con 25 idiomas
- Enfocada en la privacidad - Sin recopilación de datos, solo procesamiento local

Cómo usar

1. Instala la extensión desde la tienda de tu navegador
2. Haz clic en el icono de Tab Sorter o usa los atajos de teclado
3. Selecciona tu método de ordenación preferido
4. Tus pestañas se organizarán al instante

Compatibilidad del navegador

- Firefox - Disponible en Mozilla Add-ons
- Chrome/Chromium - Disponible en Chrome Web Store
- Funciona con todos los navegadores basados en Chromium

Instalación

Firefox
Visita la tienda de complementos de Firefox para instalar.

Chrome
Visita Chrome Web Store para instalar.

Privacidad

- Sin recopilación de datos
- Solo procesamiento local
- Permisos mínimos requeridos
- Código de código abierto
