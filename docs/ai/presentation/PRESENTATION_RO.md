Extensia Tab Sorter

Organizează eficient filele browserului

Tab Sorter este o extensie de browser care te ajută să organizezi filele deschise folosind diverse metode de sortare. Păstrează navigarea ordonată și găsește rapid filele.

Funcționalități

Opțiuni de sortare
- După titlu - Organizare alfabetică
- După URL/domeniu - Grupează site-uri similare
- După favicon - Grupare vizuală după pictogramele site-urilor
- Cele mai recent utilizate - Sortare după activitatea recentă
- Amestecă - Ordine aleatorie a filelor

Suport pentru grupuri de file
- Respectă grupurile de file ale browserului la sortare (Chrome 89+, Firefox 137+)
- Filele din fiecare grup sunt sortate separat
- Grupurile își păstrează pozițiile originale
- Opțiune de dezactivare pentru comportamentul clasic

Scurtături de tastatură
- Ctrl+Shift+Spațiu - Sortează filele cu metoda preferată
- Ctrl+Shift+L - Extrage domeniul (mută filele aceluiași domeniu într-o fereastră nouă)

Suport pentru file suspendate
- Opțiuni flexibile pentru gestionarea filelor suspendate (eliminate) la sortare
- Trei alegeri de poziție: Ignoră, Grupează la sfârșit sau Grupează la început
- Ajută la menținerea filelor active ușor accesibile sau la revizuirea celor suspendate mai întâi
- Funcționează cu toate metodele de sortare

Suport pentru file fixate
- Opțiune de sortare independentă a filelor fixate
- Filele fixate sunt sortate între ele rămânând fixate
- Funcționează cu toate metodele de sortare

Suport pentru mod întunecat
- Tema automată (urmează sistemul) este implicită
- Detectare automată a temei sistemului
- Selecție manuală a temei (Auto, Întunecat, Luminos)
- Schimbare instantanee a temei

Funcționalități suplimentare
- Sortare automată - Organizează automat filele noi
- Suport multi-fereastră - Funcționează în toate ferestrele browserului
- Interfață multilingvă - Suport pentru 25 de limbi
- Orientată spre confidențialitate - Fără colectare de date, doar procesare locală

Cum se utilizează

1. Instalează extensia din magazinul browserului
2. Dă clic pe pictograma Tab Sorter sau folosește scurtăturile de tastatură
3. Selectează metoda de sortare preferată
4. Filele tale vor fi organizate instantaneu

Compatibilitate browser

- Firefox - Disponibil pe Mozilla Add-ons
- Chrome/Chromium - Disponibil în Chrome Web Store
- Funcționează cu toate browserele bazate pe Chromium

Instalare

Firefox
Vizitează magazinul Firefox Add-ons pentru instalare.

Chrome
Vizitează Chrome Web Store pentru instalare.

Confidențialitate

- Fără colectare de date
- Doar procesare locală
- Permisiuni minime necesare
- Cod open source
