Tab Sorter -laajennus

Järjestä selaimen välilehdet tehokkaasti

Tab Sorter on selainlaajennus, joka auttaa järjestämään avoimet välilehdet eri lajittelumenetelmillä. Pidä selaus järjestyksessä ja löydä välilehdet nopeasti.

Ominaisuudet

Lajitteluvaihtoehdot
- Otsikon mukaan - Aakkosellinen järjestys
- URL:n/domainin mukaan - Ryhmittele samankaltaiset sivustot
- Faviconin mukaan - Visuaalinen ryhmittely sivustokuvakkeiden mukaan
- Viimeksi käytetyt - Lajittele viimeisimmän toiminnan mukaan
- Sekoita - Satunnainen välilehtijärjestys

Välilehtiryhmien tuki
- Kunnioittaa selaimen välilehtiryhmiä lajittelussa (Chrome 89+, Firefox 137+)
- Kunkin ryhmän välilehdet lajitellaan erikseen
- Ryhmät säilyttävät alkuperäiset sijaintinsa
- Vaihtoehto poistaa käytöstä klassista toimintaa varten

Pikanäppäimet
- Ctrl+Vaihto+Välilyönti - Lajittele välilehdet haluamallasi tavalla
- Ctrl+Vaihto+L - Erota domain (siirrä saman domainin välilehdet uuteen ikkunaan)

Keskeytettyjen välilehtien tuki
- Joustavat vaihtoehdot keskeytettyjen (hylättyjen) välilehtien käsittelyyn lajittelussa
- Kolme sijaintivalintaa: Ohita, Ryhmittele loppuun tai Ryhmittele alkuun
- Auttaa pitämään aktiiviset välilehdet helposti saatavilla tai tarkistamaan keskeytetyt ensin
- Toimii kaikilla lajittelumenetelmillä

Kiinnitettyjen välilehtien tuki
- Vaihtoehto kiinnitettyjen välilehtien itsenäiseen lajitteluun
- Kiinnitetyt välilehdet lajitellaan keskenään pysyen kiinnitettyinä
- Toimii kaikilla lajittelumenetelmillä

Tumman tilan tuki
- Automaattinen teema (seuraa järjestelmää) on oletus
- Automaattinen järjestelmäteeman tunnistus
- Manuaalinen teeman valinta (Auto, Tumma, Vaalea)
- Välitön teeman vaihto

Lisäominaisuudet
- Automaattinen lajittelu - Järjestä uudet välilehdet automaattisesti
- Usean ikkunan tuki - Toimii kaikissa selainikkunoissa
- Monikielinen käyttöliittymä - Tuki 25 kielelle
- Yksityisyyteen keskittyvä - Ei tiedonkeruuta, vain paikallinen käsittely

Käyttö

1. Asenna laajennus selaimen kaupasta
2. Napsauta Tab Sorter -kuvaketta tai käytä pikanäppäimiä
3. Valitse haluamasi lajittelumenetelmä
4. Välilehtesi järjestetään välittömästi

Selainyhteensopivuus

- Firefox - Saatavilla Mozilla Add-onsissa
- Chrome/Chromium - Saatavilla Chrome Web Storessa
- Toimii kaikissa Chromium-pohjaisissa selaimissa

Asennus

Firefox
Käy Firefox Add-ons -kaupassa asentaaksesi.

Chrome
Käy Chrome Web Storessa asentaaksesi.

Yksityisyys

- Ei tiedonkeruuta
- Vain paikallinen käsittely
- Vähimmäisoikeudet vaaditaan
- Avoimen lähdekoodin koodi
