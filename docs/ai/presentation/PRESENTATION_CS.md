Rozšíření Tab Sorter

Efektivně organizujte karty prohlížeče

Tab Sorter je rozšíření prohlížeče, které vám pomáhá organizovat otevřené karty pomocí různých metod řazení. Udržujte prohlížení přehledné a rychle najděte karty.

Funkce

Možnosti řazení
- Podle názvu - Abecední uspořádání
- Podle URL/domény - Seskupení podobných webů
- Podle favicon - Vizuální seskupení podle ikon webů
- Naposledy použité - Řazení podle nedávné aktivity
- Zamíchat - Náhodné pořadí karet

Podpora skupin karet
- Respektuje skupiny karet prohlížeče při řazení (Chrome 89+, Firefox 137+)
- Karty v rámci každé skupiny se řadí samostatně
- Skupiny si zachovávají původní pozice
- Možnost vypnutí pro klasické chování

Klávesové zkratky
- Ctrl+Shift+Mezerník - Seřadit karty preferovanou metodou
- Ctrl+Shift+L - Extrahovat doménu (přesunout karty stejné domény do nového okna)

Podpora pozastavených karet
- Flexibilní možnosti pro zacházení s pozastavenými (zahozenými) kartami při řazení
- Tři volby pozice: Ignorovat, Seskupit na konci nebo Seskupit na začátku
- Pomáhá udržet aktivní karty snadno dostupné nebo nejprve zkontrolovat pozastavené
- Funguje se všemi metodami řazení

Podpora připnutých karet
- Možnost nezávislého řazení připnutých karet
- Připnuté karty se řadí mezi sebou, zatímco zůstávají připnuté
- Funguje se všemi metodami řazení

Podpora tmavého režimu
- Automatický motiv (podle systému) je výchozí
- Automatická detekce systémového motivu
- Ruční výběr motivu (Auto, Tmavý, Světlý)
- Okamžité přepnutí motivu

Další funkce
- Automatické řazení - Automatická organizace nových karet
- Podpora více oken - Funguje ve všech oknech prohlížeče
- Vícejazyčné rozhraní - Podpora 25 jazyků
- Zaměřeno na soukromí - Žádný sběr dat, pouze lokální zpracování

Jak používat

1. Nainstalujte rozšíření z obchodu prohlížeče
2. Klikněte na ikonu Tab Sorter nebo použijte klávesové zkratky
3. Vyberte preferovanou metodu řazení
4. Vaše karty budou okamžitě uspořádány

Kompatibilita prohlížečů

- Firefox - Dostupné v Mozilla Add-ons
- Chrome/Chromium - Dostupné v Chrome Web Store
- Funguje se všemi prohlížeči založenými na Chromium

Instalace

Firefox
Navštivte obchod Firefox Add-ons pro instalaci.

Chrome
Navštivte Chrome Web Store pro instalaci.

Soukromí
