Estensione Tab Sorter

Organizza le schede del browser in modo efficiente

Tab Sorter è un'estensione del browser che ti aiuta a organizzare le schede aperte utilizzando vari metodi di ordinamento. Mantieni la navigazione ordinata e trova rapidamente le schede.

Funzionalità

Opzioni di ordinamento
- Per titolo - Organizzazione alfabetica
- Per URL/dominio - Raggruppa siti web simili
- Per favicon - Raggruppamento visivo per icone dei siti
- Più recentemente usate - Ordina per attività recente
- Mescola - Randomizza l'ordine delle schede

Supporto gruppi di schede
- Rispetta i gruppi di schede del browser durante l'ordinamento (Chrome 89+, Firefox 137+)
- Le schede all'interno di ogni gruppo vengono ordinate separatamente
- I gruppi mantengono le loro posizioni originali
- Opzione per disabilitare e tornare al comportamento classico

Scorciatoie da tastiera
- Ctrl+Maiusc+Spazio - Ordina le schede con il metodo preferito
- Ctrl+Maiusc+L - Estrai dominio (sposta le schede dello stesso dominio in una nuova finestra)

Supporto schede sospese
- Opzioni flessibili per gestire le schede sospese (scartate) durante l'ordinamento
- Tre scelte di posizione: Ignora, Raggruppa alla fine o Raggruppa all'inizio
- Aiuta a mantenere le schede attive facilmente accessibili o rivedere prima quelle sospese
- Funziona con tutti i metodi di ordinamento

Supporto schede bloccate
- Opzione per ordinare le schede bloccate in modo indipendente
- Le schede bloccate vengono ordinate tra loro rimanendo bloccate
- Funziona con tutti i metodi di ordinamento

Supporto modalità scura
- Il tema automatico (segue il sistema) è quello predefinito
- Rilevamento automatico del tema di sistema
- Selezione manuale del tema (Auto, Scuro, Chiaro)
- Cambio tema istantaneo

Funzionalità aggiuntive
- Ordinamento automatico - Organizza automaticamente le nuove schede
- Supporto multi-finestra - Funziona in tutte le finestre del browser
- Interfaccia multilingue - Supporto per 25 lingue
- Orientata alla privacy - Nessuna raccolta dati, solo elaborazione locale

Come usare

1. Installa l'estensione dallo store del browser
2. Fai clic sull'icona Tab Sorter o usa le scorciatoie da tastiera
3. Seleziona il metodo di ordinamento preferito
4. Le tue schede verranno organizzate all'istante

Compatibilità browser

- Firefox - Disponibile su Mozilla Add-ons
- Chrome/Chromium - Disponibile su Chrome Web Store
- Funziona con tutti i browser basati su Chromium
