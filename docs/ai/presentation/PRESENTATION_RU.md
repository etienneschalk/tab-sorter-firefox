Расширение Tab Sorter

Эффективно организуйте вкладки браузера

Tab Sorter — это расширение браузера, которое помогает организовать открытые вкладки с помощью различных методов сортировки. Держите просмотр в порядке и быстро находите нужные вкладки.

Возможности

Варианты сортировки
- По заголовку - Алфавитная организация
- По URL/домену - Группировка похожих сайтов
- По favicon - Визуальная группировка по иконкам сайтов
- Недавно использованные - Сортировка по недавней активности
- Перемешать - Случайный порядок вкладок

Поддержка групп вкладок
- Учитывает группы вкладок браузера при сортировке (Chrome 89+, Firefox 137+)
- Вкладки внутри каждой группы сортируются отдельно
- Группы сохраняют свои исходные позиции
- Опция отключения для классического поведения

Горячие клавиши
- Ctrl+Shift+Пробел - Сортировать вкладки предпочитаемым способом
- Ctrl+Shift+L - Извлечь домен (переместить вкладки одного домена в новое окно)

Поддержка приостановленных вкладок
- Гибкие параметры обработки приостановленных (отброшенных) вкладок при сортировке
- Три варианта позиции: Игнорировать, Группировать в конце или Группировать в начале
- Помогает держать активные вкладки легко доступными или сначала просматривать приостановленные
- Работает со всеми методами сортировки

Поддержка закреплённых вкладок
- Опция независимой сортировки закреплённых вкладок
- Закреплённые вкладки сортируются между собой, оставаясь закреплёнными
- Работает со всеми методами сортировки

Поддержка тёмной темы
- Автоматическая тема (следует за системой) по умолчанию
- Автоматическое определение системной темы
- Ручной выбор темы (Авто, Тёмная, Светлая)
- Мгновенное переключение темы

Дополнительные возможности
- Автосортировка - Автоматическая организация новых вкладок
- Поддержка нескольких окон - Работает во всех окнах браузера
- Многоязычный интерфейс - Поддержка 25 языков
- Ориентация на конфиденциальность - Без сбора данных, только локальная обработка

Как использовать

1. Установите расширение из магазина браузера
2. Нажмите на значок Tab Sorter или используйте горячие клавиши
3. Выберите предпочитаемый метод сортировки
4. Ваши вкладки будут организованы мгновенно

Совместимость с браузерами

- Firefox - Доступно в Mozilla Add-ons
- Chrome/Chromium - Доступно в Chrome Web Store
- Работает со всеми браузерами на базе Chromium

Установка

Firefox
Посетите магазин Firefox Add-ons для установки.

Chrome
Посетите Chrome Web Store для установки.

Конфиденциальность

- Без сбора данных
- Только локальная обработка
- Минимальные необходимые разрешения
- Открытый исходный код
