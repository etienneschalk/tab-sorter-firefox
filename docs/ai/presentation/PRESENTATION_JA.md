Tab Sorter 拡張機能

ブラウザのタブを効率的に整理

Tab Sorter は、さまざまな並べ替え方法で開いているタブを整理するブラウザ拡張機能です。ブラウジングを整理し、タブを素早く見つけられます。

機能

並べ替えオプション
- タイトル順 - アルファベット順に整理
- URL/ドメイン順 - 類似サイトをまとめる
- ファビコン順 - サイトアイコンで視覚的にグループ化
- 最近使用した順 - 最近の操作で並べ替え
- シャッフル - タブの順序をランダム化

タブグループのサポート
- 並べ替え時にブラウザのタブグループを尊重（Chrome 89+、Firefox 137+）
- 各グループ内のタブは個別に並べ替え
- グループは元の位置を維持
- 従来の動作に戻す無効化オプション

キーボードショートカット
- Ctrl+Shift+スペース - お好みの方法でタブを並べ替え
- Ctrl+Shift+L - ドメインを抽出（同じドメインのタブを新しいウィンドウに移動）

サスペンドされたタブのサポート
- 並べ替え時のサスペンド（破棄）タブの柔軟な処理オプション
- 3つの位置選択：無視、末尾にグループ化、先頭にグループ化
- アクティブなタブをアクセスしやすく保つ、またはサスペンドされたタブを先に確認
- すべての並べ替え方法で動作

ピン留めタブのサポート
- ピン留めタブを独立して並べ替えるオプション
- ピン留めタブはピン留めのまま互いに並べ替え
- すべての並べ替え方法で動作

ダークモードのサポート
- 自動テーマ（システムに従う）がデフォルト
- システムテーマの自動検出
- 手動テーマ選択（自動、ダーク、ライト）
- テーマの即時切り替え

追加機能
- 自動並べ替え - 新しいタブを自動的に整理
- 複数ウィンドウのサポート - すべてのブラウザウィンドウで動作
- 多言語インターフェース - 25言語に対応
- プライバシー重視 - データ収集なし、ローカル処理のみ

使い方

1. ブラウザのストアから拡張機能をインストール
2. Tab Sorter アイコンをクリックするかキーボードショートカットを使用
3. お好みの並べ替え方法を選択
4. タブが即座に整理されます

ブラウザの互換性

- Firefox - Mozilla Add-ons で利用可能
- Chrome/Chromium - Chrome ウェブストアで利用可能
- Chromium ベースのすべてのブラウザで動作

インストール

Firefox
Firefox Add-ons ストアにアクセスしてインストール。

Chrome
Chrome ウェブストアにアクセスしてインストール。

プライバシー

- データ収集なし
- ローカル処理のみ
- 最小限の権限のみ必要
- オープンソースコード
