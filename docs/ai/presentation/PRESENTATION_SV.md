Tab Sorter-tillägg

Organisera dina webbläsarflikar effektivt

Tab Sorter är ett webbläsartillägg som hjälper dig att organisera dina öppna flikar med olika sorteringsmetoder. Håll din surfning organiserad och hitta flikar snabbt.

Funktioner

Sorteringsalternativ
- Efter titel - Alfabetisk organisation
- Efter URL/domän - Gruppera liknande webbplatser
- Efter favicon - Visuell gruppering efter webbplatsikoner
- Senast använda - Sortera efter senaste aktivitet
- Blanda - Slumpa flikordning

Stöd för flikgrupper
- Respekterar webbläsarens flikgrupper vid sortering (Chrome 89+, Firefox 137+)
- Flikar inom varje grupp sorteras separat
- Grupper behåller sina ursprungliga positioner
- Alternativ för att inaktivera för klassiskt beteende

Kortkommandon
- Ctrl+Skift+Mellanslag - Sortera flikar med din föredragna metod
- Ctrl+Skift+L - Extrahera domän (flytta flikar från samma domän till ett nytt fönster)

Stöd för vilande flikar
- Flexibla alternativ för hantering av vilande (kasserade) flikar vid sortering
- Tre positionsval: Ignorera, Gruppera i slutet eller Gruppera i början
- Hjälper till att hålla aktiva flikar lättillgängliga eller granska vilande först
- Fungerar med alla sorteringsmetoder

Stöd för fästa flikar
- Alternativ för att sortera fästa flikar oberoende
- Fästa flikar sorteras sinsemellan medan de förblir fästa
- Fungerar med alla sorteringsmetoder

Stöd för mörkt läge
- Automatiskt tema (följer systemet) är standard
- Automatisk systemtemadetektering
- Manuellt temaval (Auto, Mörkt, Ljust)
- Omedelbar temaväxling

Ytterligare funktioner
- Automatisk sortering - Organisera nya flikar automatiskt
- Stöd för flera fönster - Fungerar i alla webbläsarfönster
- Flerspråkigt gränssnitt - Stöd för 25 språk
- Integritetsfokuserat - Ingen datainsamling, endast lokal bearbetning

Så använder du

1. Installera tillägget från din webbläsares butik
2. Klicka på Tab Sorter-ikonen eller använd kortkommandon
3. Välj din föredragna sorteringsmetod
4. Dina flikar organiseras omedelbart

Webbläsarkompatibilitet

- Firefox - Tillgängligt på Mozilla Add-ons
- Chrome/Chromium - Tillgängligt i Chrome Web Store
- Fungerar med alla Chromium-baserade webbläsare

Installation

Firefox
Besök Firefox Add-ons Store för att installera.

Chrome
Besök Chrome Web Store för att installera.

Integritet

- Minimala behörigheter krävs
- Öppen källkod
