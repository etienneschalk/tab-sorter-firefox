Extensão Tab Sorter

Organize suas abas do navegador com eficiência

Tab Sorter é uma extensão de navegador que ajuda você a organizar suas abas abertas usando vários métodos de ordenação. Mantenha sua navegação organizada e encontre abas rapidamente.

Recursos

Opções de ordenação
- Por título - Organização alfabética
- Por URL/domínio - Agrupar sites semelhantes
- Por favicon - Agrupamento visual por ícones dos sites
- Mais recentemente usadas - Ordenar por atividade recente
- Embaralhar - Randomizar a ordem das abas

Suporte a grupos de abas
- Respeita os grupos de abas do navegador durante a ordenação (Chrome 89+, Firefox 137+)
- As abas dentro de cada grupo são ordenadas separadamente
- Os grupos mantêm suas posições originais
- Opção para desativar e voltar ao comportamento clássico

Atalhos de teclado
- Ctrl+Shift+Espaço - Ordenar abas com seu método preferido
- Ctrl+Shift+L - Extrair domínio (mover abas do mesmo domínio para uma nova janela)

Suporte a abas suspensas
- Opções flexíveis para lidar com abas suspensas (descartadas) ao ordenar
- Três opções de posição: Ignorar, Agrupar no final ou Agrupar no início
- Ajuda a manter as abas ativas facilmente acessíveis ou revisar as suspensas primeiro
- Funciona com todos os métodos de ordenação

Suporte a abas fixadas
- Opção para ordenar abas fixadas de forma independente
- Abas fixadas são ordenadas entre si permanecendo fixadas
- Funciona com todos os métodos de ordenação

Suporte ao modo escuro
- O tema automático (segue o sistema) é o padrão
- Detecção automática do tema do sistema
- Seleção manual do tema (Auto, Escuro, Claro)
- Troca de tema instantânea

Recursos adicionais
- Ordenação automática - Organizar automaticamente novas abas
- Suporte entre janelas - Funciona em todas as janelas do navegador
- Interface multilíngue - Suporte para 25 idiomas
- Focada em privacidade - Sem coleta de dados, apenas processamento local

Como usar

1. Instale a extensão na loja do seu navegador
2. Clique no ícone do Tab Sorter ou use os atalhos de teclado
3. Selecione seu método de ordenação preferido
4. Suas abas serão organizadas instantaneamente

Compatibilidade do navegador

- Firefox - Disponível na Mozilla Add-ons
- Chrome/Chromium - Disponível na Chrome Web Store
- Funciona com todos os navegadores baseados em Chromium
