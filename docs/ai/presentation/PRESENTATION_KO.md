Tab Sorter 확장 프로그램

브라우저 탭을 효율적으로 정리하세요

Tab Sorter는 다양한 정렬 방법으로 열린 탭을 정리하는 데 도움이 되는 브라우저 확장 프로그램입니다. 브라우징을 정돈하고 탭을 빠르게 찾으세요.

기능

정렬 옵션
- 제목순 - 알파벳 순 정리
- URL/도메인순 - 유사한 웹사이트 그룹화
- 파비콘순 - 사이트 아이콘으로 시각적 그룹화
- 최근 사용순 - 최근 활동으로 정렬
- 섞기 - 탭 순서 무작위화

탭 그룹 지원
- 정렬 시 브라우저 탭 그룹 존중 (Chrome 89+, Firefox 137+)
- 각 그룹 내 탭은 별도로 정렬
- 그룹은 원래 위치 유지
- 기존 동작으로 되돌리는 비활성화 옵션

키보드 단축키
- Ctrl+Shift+스페이스 - 선호하는 방법으로 탭 정렬
- Ctrl+Shift+L - 도메인 추출 (같은 도메인 탭을 새 창으로 이동)

일시 중단된 탭 지원
- 정렬 시 일시 중단(폐기)된 탭 처리를 위한 유연한 옵션
- 세 가지 위치 선택: 무시, 끝에 그룹화, 시작에 그룹화
- 활성 탭을 쉽게 접근하거나 일시 중단된 탭을 먼저 검토
- 모든 정렬 방법에서 작동

고정된 탭 지원
- 고정된 탭을 독립적으로 정렬하는 옵션
- 고정된 탭은 고정 상태를 유지하며 서로 정렬
- 모든 정렬 방법에서 작동

다크 모드 지원
- 자동 테마(시스템 따름)가 기본값
- 시스템 테마 자동 감지
- 수동 테마 선택 (자동, 다크, 라이트)
- 즉시 테마 전환

추가 기능
- 자동 정렬 - 새 탭 자동 정리
- 여러 창 지원 - 모든 브라우저 창에서 작동
- 다국어 인터페이스 - 25개 언어 지원
- 개인정보 보호 중심 - 데이터 수집 없음, 로컬 처리만

사용 방법

1. 브라우저 스토어에서 확장 프로그램 설치
2. Tab Sorter 아이콘을 클릭하거나 키보드 단축키 사용
3. 선호하는 정렬 방법 선택
4. 탭이 즉시 정리됩니다

브라우저 호환성

- Firefox - Mozilla Add-ons에서 이용 가능
- Chrome/Chromium - Chrome 웹 스토어에서 이용 가능
- Chromium 기반 모든 브라우저에서 작동
