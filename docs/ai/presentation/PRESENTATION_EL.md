Επέκταση Tab Sorter

Οργανώστε αποτελεσματικά τις καρτέλες του προγράμματος περιήγησης

Το Tab Sorter είναι μια επέκταση προγράμματος περιήγησης που σας βοηθά να οργανώνετε τις ανοιχτές καρτέλες χρησιμοποιώντας διάφορες μεθόδους ταξινόμησης. Κρατήστε την περιήγησή σας οργανωμένη και βρείτε γρήγορα καρτέλες.

Λειτουργίες

Επιλογές ταξινόμησης
- Κατά τίτλο - Αλφαβητική οργάνωση
- Κατά URL/τομέα - Ομαδοποίηση παρόμοιων ιστοτόπων
- Κατά favicon - Οπτική ομαδοποίηση κατά εικονίδια ιστοτόπων
- Πιο πρόσφατα χρησιμοποιημένες - Ταξινόμηση κατά πρόσφατη δραστηριότητα
- Ανακάτεμα - Τυχαία σειρά καρτελών

Υποστήριξη ομάδων καρτελών
- Σέβεται τις ομάδες καρτελών του προγράμματος περιήγησης κατά την ταξινόμηση (Chrome 89+, Firefox 137+)
- Οι καρτέλες μέσα σε κάθε ομάδα ταξινομούνται ξεχωριστά
- Οι ομάδες διατηρούν τις αρχικές τους θέσεις
- Επιλογή απενεργοποίησης για κλασική συμπεριφορά

Συντομεύσεις πληκτρολογίου
- Ctrl+Shift+Διάστημα - Ταξινόμηση καρτελών με την προτιμώμενη μέθοδο
- Ctrl+Shift+L - Εξαγωγή τομέα (μετακίνηση καρτελών ίδιου τομέα σε νέο παράθυρο)

Υποστήριξη ανασταλμένων καρτελών
- Ευέλικτες επιλογές για χειρισμό ανασταλμένων (απορριφθεισών) καρτελών κατά την ταξινόμηση
- Τρεις επιλογές θέσης: Αγνόηση, Ομαδοποίηση στο τέλος ή Ομαδοποίηση στην αρχή
- Βοηθά να κρατούνται οι ενεργές καρτέλες εύκολα προσβάσιμες ή να ελέγχονται πρώτα οι ανασταλμένες
- Λειτουργεί με όλες τις μεθόδους ταξινόμησης

Υποστήριξη καρφιτσωμένων καρτελών
- Επιλογή ανεξάρτητης ταξινόμησης καρφιτσωμένων καρτελών
- Οι καρφιτσωμένες καρτέλες ταξινομούνται μεταξύ τους παραμένοντας καρφιτσωμένες
- Λειτουργεί με όλες τις μεθόδους ταξινόμησης

Υποστήριξη σκοτεινής λειτουργίας
- Το αυτόματο θέμα (ακολουθεί το σύστημα) είναι προεπιλογή
- Αυτόματη ανίχνευση θέματος συστήματος
- Χειροκίνητη επιλογή θέματος (Αυτόματο, Σκοτεινό, Φωτεινό)
- Άμεση εναλλαγή θέματος

Πρόσθετες λειτουργίες
- Αυτόματη ταξινόμηση - Αυτόματη οργάνωση νέων καρτελών
- Υποστήριξη πολλαπλών παραθύρων - Λειτουργεί σε όλα τα παράθυρα του προγράμματος περιήγησης
- Πολύγλωσσο περιβάλλον - Υποστήριξη 25 γλωσσών
- Εστίαση στην ιδιωτικότητα - Χωρίς συλλογή δεδομένων, μόνο τοπική επεξεργασία

Πώς να χρησιμοποιήσετε

1. Εγκαταστήστε την επέκταση από το κατάστημα του προγράμματος περιήγησης
2. Κάντε κλικ στο εικονίδιο Tab Sorter ή χρησιμοποιήστε συντομεύσεις πληκτρολογίου
3. Επιλέξτε την προτιμώμενη μέθοδο ταξινόμησης
4. Οι καρτέλες σας θα οργανωθούν αμέσως

Συμβατότητα προγράμματος περιήγησης

- Firefox - Διαθέσιμο στα Mozilla Add-ons
- Chrome/Chromium - Διαθέσιμο στο Chrome Web Store
- Λειτουργεί με όλα τα προγράμματα περιήγησης βασισμένα σε Chromium
