Tab Sorter Uzantısı

Tarayıcı sekmelerinizi verimli şekilde düzenleyin

Tab Sorter, açık sekmelerinizi çeşitli sıralama yöntemleriyle düzenlemenize yardımcı olan bir tarayıcı uzantısıdır. Gezinmenizi düzenli tutun ve sekmeleri hızla bulun.

Özellikler

Sıralama seçenekleri
- Başlığa göre - Alfabetik düzenleme
- URL/etki alanına göre - Benzer web sitelerini gruplama
- Favicon'a göre - Site simgelerine göre görsel gruplama
- En son kullanılan - Son etkinliğe göre sıralama
- Karıştır - Sekme sırasını rastgeleleştirme

Sekme grupları desteği
- Sıralama sırasında tarayıcı sekme gruplarına saygı gösterir (Chrome 89+, Firefox 137+)
- Her gruptaki sekmeler ayrı ayrı sıralanır
- Gruplar orijinal konumlarını korur
- Klasik davranış için devre dışı bırakma seçeneği

Klavye kısayolları
- Ctrl+Shift+Boşluk - Tercih ettiğiniz yöntemle sekmeleri sırala
- Ctrl+Shift+L - Etki alanını ayıkla (aynı etki alanındaki sekmeleri yeni pencereye taşı)

Askıya alınmış sekmeler desteği
- Sıralama sırasında askıya alınmış (atılmış) sekmeleri yönetmek için esnek seçenekler
- Üç konum seçeneği: Yoksay, Sonda grupla veya Başta grupla
- Aktif sekmeleri kolay erişilebilir tutmaya veya askıya alınmışları önce incelemeye yardımcı olur
- Tüm sıralama yöntemleriyle çalışır

Sabitlenmiş sekmeler desteği
- Sabitlenmiş sekmeleri bağımsız sıralama seçeneği
- Sabitlenmiş sekmeler sabit kalırken kendi aralarında sıralanır
- Tüm sıralama yöntemleriyle çalışır

Karanlık mod desteği
- Otomatik tema (sistemi izler) varsayılandır
- Otomatik sistem teması algılama
- Manuel tema seçimi (Otomatik, Karanlık, Açık)
- Anında tema değiştirme

Ek özellikler
- Otomatik sıralama - Yeni sekmeleri otomatik düzenleme
- Çoklu pencere desteği - Tüm tarayıcı pencerelerinde çalışır
- Çok dilli arayüz - 25 dil desteği
- Gizlilik odaklı - Veri toplama yok, yalnızca yerel işleme

Nasıl kullanılır

1. Uzantıyı tarayıcı mağazanızdan yükleyin
2. Tab Sorter simgesine tıklayın veya klavye kısayollarını kullanın
3. Tercih ettiğiniz sıralama yöntemini seçin
4. Sekmeleriniz anında düzenlenecektir

Tarayıcı uyumluluğu

- Firefox - Mozilla Add-ons'ta mevcut
- Chrome/Chromium - Chrome Web Store'da mevcut
- Chromium tabanlı tüm tarayıcılarla çalışır

Kurulum

Firefox
Yüklemek için Firefox Eklentiler Mağazası'nı ziyaret edin.

Chrome
Yüklemek için Chrome Web Store'u ziyaret edin.

Gizlilik

- Veri toplama yok
- Yalnızca yerel işleme
- Minimum izin gerekir
- Açık kaynak kod
